1. WHAT ENGEL IS

Engel is a desktop AI companion. Three things make it different:

PropertyWhat it means
Local-firstThe desktop app, chat history, and most actions run on your machine. No cloud account.
Bridges-not-integrationsType browser ai connect chatgpt to talk to ChatGPT, evolve list to use Imbue's evolver, ephify build to map a project. Each external thing is one chat command.
Read-only by defaultThe "AI plan" lane shows what would happen before anything runs. You proceed manually. No autonomous file writes.

There are two executables:

  • Engel.exe — the everyday companion (orb on desktop, chat window).
  • EngelSuperSwarmHive3D.exe — the power-user dashboard with the colony hives, queens, expansion charts, permissions.

2. INSTALLING & LAUNCHING

First-time setup

  1. Copy Engel.exe and EngelSuperSwarmHive3D.exe to any folder.
  2. Make sure Python 3.10+ is installed if you want the chat bridges to call Playwright/Ephify/Evolver. (The exe runs without them, the bridges fail gracefully.)
  3. For browser-AI bridges (Claude/ChatGPT/Gemini in a real browser), once:

```

python -m playwright install chromium

```

Launching

Double-click Engel.exe. A small orb appears in the upper-right of your screen with a tray icon.

Closed mode — a small floating orb. Drag to move. Double-click to open the chat window.

3. THE COMPANION WINDOW

3.1 Closed (orb) mode

When closed, Engel sits as a small frameless orb that stays on top of other windows. You can:

  • Drag anywhere to move it
  • Double-click to expand into the chat window
  • Drop a file or folder onto the orb — Engel will summarize it (if the path is allowed)
  • Right-click the tray icon to quit cleanly

4. CHAT COMMANDS YOU CAN TYPE

The chat input understands a set of bridge commands. Each command has its own status subcommand that explains what's missing if anything.

4.1 Browser AI bridge

Talk to Claude, ChatGPT, Gemini, etc. through a real browser session. No API keys.

browser ai connect chatgpt    # opens chatgpt.com in a browser; log in if prompted
browser ai connect claude     # claude.ai
browser ai connect duck       # duck.ai (no login, FREE)
browser ai connect google     # gemini.google.com (needs Google login)
browser ai disconnect         # close the session
browser ai switch <provider>  # disconnect + connect a different provider

Once connected, type any message in Engel chat and it's sent to that AI. The response comes back into the chat.

Requires: pip install playwright && python -m playwright install chromium (once).

4.2 Evolve (darwinian evolver + evolver-main)

evolve status                       # bridge state
evolve list                         # list darwinian problems
evolve run <problem> [iters]        # start a darwinian evolution as subprocess
evolve node <subcommand>            # call evolver-main (Node.js) directly
evolve stop                         # terminate current run
evolve tail                         # last 50 lines of running output

Requires: Python 3.11+ for evolve run (3.10 works for list). Node.js for evolve node.

4.3 Ephify

Build a queryable knowledge graph from any folder of code/docs/PDFs.

ephify status                # bridge + dependency state
ephify build [path]          # build graph (default: cwd) -> graph.html / GRAPH_REPORT.md / graph.json
ephify query <question>      # query the current graph
ephify explain <topic>       # explain a topic
ephify export callflow-html  # generate Mermaid call-flow diagram
ephify install-deps          # install upstream dependency package

4.4 Sandbox (CubeSandbox client)

E2B-compatible client. Needs a remote Linux+KVM host running CubeSandbox.

sandbox status                  # bridge + health check
sandbox endpoint <url>          # point at your CubeSandbox server
sandbox key <api_key>           # auth header
sandbox list                    # list sandboxes
sandbox create [template]       # create a sandbox
sandbox info <id>               # get details
sandbox kill <id>               # destroy
sandbox use <id>                # set active sandbox
sandbox pause / connect <id>    # pause / resume

4.5 jcode

Rust-based AI coding agent. Runs as subprocess if you build/install the binary.

jcode status                # bridge + binary detection
jcode build                 # cargo build --release (10+ min first time)
jcode version / help        # print version / CLI help
jcode run <prompt>          # run jcode with a prompt
jcode <anything>            # anything else is treated as a prompt
jcode stop / tail           # control & inspect

4.6 Cursor kit

Library of agent personas / workflows / skills curated for Cursor IDE. Read-only.

cursor status              # kit summary
cursor list                # list everything
cursor agents              # 5 personas
cursor workflows           # 4 workflows
cursor skills              # 7 skills
cursor show <name>         # print full file content
cursor prompt <name>       # wrap as system prompt for paste-into-brain-provider
cursor search <term>       # search markdown across the kit

4.7 OpenHuman

Same shape as cursor — read-only library of agent personas + docs.

openhuman status              # bridge + counts
openhuman agents              # 14 Claude personas
openhuman commands            # /commands (e.g. ship-and-babysit)
openhuman docs                # 14 internal docs
openhuman show <name>         # print full file
openhuman prompt <name>       # wrap as system prompt
openhuman search <term>       # full-text search

4.8 Humanizer

Strip AI tells from text.

humanize status     # bridge state
humanize show       # print the full SKILL.md
humanize <text>     # wrap the skill around your text, ready to send to a brain provider

The bridge returns a structured prompt — you then send it to whatever LLM you're connected to via browser AI.

4.9 LocalSend

Real protocol implementation. Discover + send files to LocalSend devices on your LAN.

localsend status              # bridge state + known devices
localsend scan [seconds]      # UDP multicast scan (default 5s)
localsend list                # list discovered devices
localsend info <ip[:port]>    # fetch device info
localsend send <ip[:port]> <file>  # send a file
localsend forget              # clear device list

4.10 Eng3d

Next.js + React-Three-Fiber "AI office" web app. Bridge runs the dev server and opens the browser.

eng3d status               # bridge + dependency check
eng3d install              # npm install (slow first time)
eng3d dev                  # start dev server on localhost:3000
eng3d demo                 # start built-in demo gateway adapter
eng3d open                 # open the 3D office in your browser
eng3d docs                 # list 28 internal spec docs
eng3d show <name>          # print a spec doc
eng3d stop / tail          # control & inspect

6. MOBILE APPS

Two Flutter apps live in mobile/:

6.1 Engel Remote Worker (mobile/engel_remote_worker)

Companion app that pairs with your desktop Engel via LAN.

  • 8 tabs: Dashboard / Status / Mobile / Logs / Settings / Bridge / Notifications / Chat
  • Auto-discovers Engel on the LAN via UDP broadcast (port 8766)
  • Chat tab talks to Engel through the /chat LAN endpoint
  • Dark terminal theme

6.2 Engel Monitor (mobile/engel_monitor)

Phone-as-system-monitor for the desktop.

  • CPU load + temp · GPU load + temp meters
  • Latest screenshot viewer
  • Limp Mode button (hold 3 seconds to toggle emergency power throttle)
  • Chat to Engel
  • Auto-discovers Engel via UDP

Pairing

  1. Make sure the desktop Engel has Mobile ON (button in the right column)
  2. Open either mobile app on a phone on the same Wi-Fi
  3. The app auto-discovers engel:1 beacons and auto-fills host/port/pairing-code
  4. Confirm; you're paired

7. TROUBLESHOOTING

"Browser AI connect failed: Executable doesn't exist at ...\\chromium-1223\\chrome-win64\\chrome.exe"

Playwright is bundled but the actual browser is not (200MB). Run once in a terminal:

python -m playwright install chromium

Then retry browser ai connect ....

Mobile app doesn't find Engel on Wi-Fi

  • Make sure both devices are on the same Wi-Fi network
  • Check that Mobile ON is enabled in Engel's right column
  • Some routers block UDP multicast; try restarting the router or moving the phone closer

A bridge command says "X not installed"

Each bridge's status subcommand prints the exact pip / cargo / npm command needed. Example:

ephify status

Will tell you ephify install-deps is needed if it is.

Engel chat says "I didn't recognize that"

If you get this on a free-form message (not a command), the command router may be over-strict. Try typing it as a clear sentence, or connect a browser AI first (browser ai connect duck) so the brain provider catches it.

Want to start fresh

Quit Engel from the tray icon, then delete browser_profile/ in the Engel folder to clear all saved browser sessions.
