# Markdown content authoring

The `/docs` route renders `src/content/platform-overview.md` with `react-markdown`.

Use standard Markdown headings, lists, emphasis, links, and code blocks. Raw HTML is intentionally not enabled. Keep documentation public-safe and avoid internal implementation details, addresses, credentials, logs, device names, or personal information.

Additional Markdown documents can be added under `src/content/` and mapped to routes in `src/App.tsx`.
