# Engel AI Labs brand assets

Approved starter assets for the public website.

- `engel-mark.svg` — compact constellation mark for favicons and square placements
- `engel-wordmark.svg` — horizontal company wordmark
- `platform-architecture.svg` — public conceptual architecture diagram

Palette:

- Void: `#06101D`
- Deep space: `#0A1729`
- Ice: `#EAF7FF`
- Signal blue: `#22C8FF`
- Signal green: `#42F5A7`
- Muted orbit: `#8EA9BD`

These vector files contain no private system details. Keep clear space around the mark equal to the diameter of its smallest orbit node.
